# Catálogo de Adoção de Gatos

## Sobre o Projeto
Este é um projeto web simples de um catálogo de adoção de felinos, desenvolvido como parte da atividade de Qualidade de Código. O foco principal não é a complexidade da aplicação, mas sim servir de base para o fluxo de versionamento, deploy automatizado e análise estática de código.

Atenção: O código-fonte deste repositório contém intencionalmente falhas de qualidade, como "code smells" e duplicações, elaborados para detecção e correção através do SonarQube.

## Tecnologias Utilizadas
- Next.js
- React
- TypeScript
- Tailwind CSS

## Como Rodar Localmente

1. Clone este repositório em sua máquina:
git clone URL_DO_SEU_REPOSITORIO

2. Acesse a pasta do projeto:
cd catalogo-gatos

3. Instale as dependências necessárias:
npm install

4. Inicie o servidor local de desenvolvimento:
npm run dev

5. Abra o navegador e acesse:
http://localhost:3000
